# Time Stone Sound Cues

Drop your custom MP3 files into this directory (`sounds/timestone/`):

- `snap.mp3` — The crisp metallic Infinity Gauntlet snap click (t = 0.0s)
- `whoosh.mp3` — Cinematic vacuum whoosh / ash dissolution (t = 0.3s)
- `timestone.mp3` — Glowing mystical Doctor Strange time rune harmonic chord / bell chime (t = 1.8s)
- `run.mp3` — Clean emerald harmonic chime when test cases pass (Run)
- `error.mp3` — Reality distortion ping on Wrong Answer / Error

Note: If any of these files are missing, LeetGlow's built-in Web Audio synthesizer will automatically synthesize crisp metallic snaps, cinematic vacuum whooshes, and glowing crystal time-stone harmonics in real time, so sound effects work out of the box!
